Created:

## What I learned

1. YAML uses spaces for indentation. Tabs should not be used.
2. Lists can be written using `-` or `[ ]`.
3. '|'keeps each line on a new line, while '>' combines the lines into a single line.
4. I used yamllint to check my YAML files.
