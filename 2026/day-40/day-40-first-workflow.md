
## Task 3 – GitHub Actions Anatomy

- `name:` gives the workflow or step a readable name.
- `on:` defines when the workflow should run.
- `jobs:` defines the work that the workflow performs.
- `runs-on:` specifies the runner where the job runs.
- `steps:` contains the individual tasks performed by a job.
- `uses:` uses an existing GitHub Action.
- `run:` executes a shell command on the runner.
